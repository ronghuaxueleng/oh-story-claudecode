# 短篇正文格式

## 工作稿结构

知乎短篇工作稿固定使用以下结构：

```text
# 《书名》

导语正文

1.

正文

2.

正文
```

- 书名只出现一次。
- 导语位于标题和 `1.` 之间，不另加“导语”标题。
- 数字节从 `1.` 开始连续递增，每个标记独占一行。
- 正文不继承大纲小节名，尾声并入最后一个数字节。
- 自检、说明、回执内容和 Markdown 分隔线不得写入正文。

## 段落与对白

- 按动作变化、信息变化、视线转移和自然换气断段，不设机械字数上限。
- 同一身体动作、感官或话轮链可以保留长句；承载多个独立节点时在自然换气点拆开。
- 不把连续现场压成一行，也不把每个短句都拆成独立段。
- 对白独立成行时必须保持说话人清楚；引号和功能词以主体原文声线及目标平台为准。
- 段间空行只服务阅读和场景呼吸，不作为硬性数量指标。

## 校验

正文完成或回修后运行：

```bash
python3 "$SKILL_ROOT/scripts/validate_zhihu_section_format.py" \
  --text "{项目目录}/正文.md"
```

校验只负责标题和数字分节格式；段落呼吸、对白效率和声线一致性由初稿终审人工判断。
