# P 拍换芯与按需热点

本规则只在用户明确要求使用热点新闻时读取。普通主体原文仿写仍须逐拍替换 P 拍事件壳，但不得检索、读取或注入新闻，`hot_news_materials` 和全部 `news_ids` 保持空数组。

## 层级边界

必须保留：

1. 故事核与关系命题。
2. 全书关系/情绪母线。
3. BID 顺序，以及每个 BID 的进入位置、核心压力和退出位置。
4. 主体全部 E 拍的内容、烈度、先后顺序和期待位移。
5. 主体全部 SF 的六维成文颗粒。
6. 主体 P 拍的数量、原序和承重功能槽位。

必须替换：

- 主体 P 拍中的人物身份、关系壳、职业领域、现场、触发方式、核心物件、证据形态、控制权实现和现实后果。
- 每个来源 P 拍只能对应一个目标 P 拍；保留的是“这一步必须完成什么”，不是“原文具体发生了什么”。
- 每条替换至少改变三个事件壳维度，其中至少两个来自 `occupation_domain / setting / trigger / evidence / control_mechanism / consequence`。

E 拍与目标 P 拍是同步双轨：E 拍规定人物和读者必须发生的情绪位移，目标 P 拍负责用新事件把该位移制造出来。即使启用热点，也禁止先写情绪说明，再在后面硬贴新闻素材。

## 热点检索

只有用户在当前任务中明确要求热点新闻时，才在 `设定.md` 完成、`小节大纲.md` 定稿前执行。禁止使用浏览器或 CDP 获取新闻；直接使用 WebSearch、公开网页或可信机构页面。单一站点打不开时更换公开来源，不得转用浏览器/CDP。

1. 先从各 BID/E 拍提炼压力机制，例如公开掉位、权限被收回、证据被平台固化、职业共同体排斥、算法误伤、制度性沉默。
2. 用“现实领域 + 压力机制 + 可见后果”组合搜索词，不拿原文人物、物件和完整事件去搜相似故事。
3. 优先检索近 30 天；没有合适机制时扩到 90 天，不得把多年旧闻包装成热点。
4. 至少选择两条不同新闻，来源于不同发布机构和站点。优先官方通报、权威媒体、行业机构和当事平台公开说明。
5. 只提取可迁移机制，不复制真实姓名、精确地址、伤亡细节、独有措辞、完整时间线或可反向识别的组合信息。

新闻不是正文声线来源，也不是事实授权。真实新闻只供应制度压力、职业规则、舆论机制、证据形态或后果机制；进入小说前必须虚构化、去标识化并重新建立因果。

## 纲层填写

用户明确启用热点后，运行 `export-template`，在既有 `纲层迁移侧车.json` 内填写，不新增新闻回执。用户未启用时保持 `hot_news_materials=[]`，并让每个 `p_beat_replacements[*].news_ids=[]`。

`hot_news_materials` 每项使用：

```json
{
  "news_id": "HN-001",
  "title": "新闻原始标题",
  "publisher": "发布机构",
  "published_at": "2026-08-10",
  "retrieved_at": "2026-08-19",
  "url": "https://example.com/news/1",
  "transferable_mechanism": "只写可迁移的现实压力、证据或后果机制",
  "fact_boundary": "说明哪些事实只用于核验，正文如何去标识化和重新虚构"
}
```

`p_beat_replacements` 与主体 P 拍等长同序。`source_ref` 由脚本预填，只填写人工判断：

```json
{
  "source_ref": "SRC-PRIMARY:P-001",
  "preserved_function": "保留该拍在 BID 中造成关系公开掉位的承重功能",
  "changed_dimensions": ["occupation_domain", "setting", "evidence", "consequence"],
  "news_ids": ["HN-001"],
  "adaptation_judgment": "说明目标细拍如何制造同一 E 拍，同时为什么已不再复刻原文事件壳"
}
```

热点模式下，不是每个目标 P 拍都必须使用新闻，但每个主体 P 拍都必须完成换芯；至少两条不同新闻分别落到两个不同目标 P 拍。篇幅极短且主体只有一个 P 拍时，最低数量随主体 P 拍降为一。

## 写作与终审

写每个区域前同时读取：对应 BID/E 拍、SF 六维颗粒、目标细拍以及该区域的 `p_beat_replacements`。落笔顺序是“新事件触发 -> 期待或控制权变化 -> E 拍形成 -> 行动与后果”，不是“情绪标签 -> 新闻说明”。

启用热点不得成为扩写理由。总字数、数字节数仍受主体锚定上限约束；热点机制应替换或加深现有 P 拍，不得另起无关支线。

初稿终审必须逐区域确认：

- 主体 P 拍承重功能仍在，目标事件已经完整兑现。
- 原人物、职业、物件、现场和完整事件壳没有回流。
- 对应 E 拍由目标事件真实制造，不是靠心理汇报补齐。
- 启用热点时，新闻机制已经小说化，正文没有真实人物识别信息或新闻原句。
- 启用热点时，使用热点的区域至少引用一条正文证据。
