# 逐节随写合规

这份规则把逐节写后检查前移到首写，同时保留对真实句子的即时验收。目标是减少返工，不是让正文背着验收表生成。

## 固定时序

每个数字小节都执行：

`组织完整场面计划与字数分配 -> start-section -> 选取本节适用规则 -> 改写成正向约束 -> 在独立暂存稿一次首写完整场面 -> 检查真实句子 -> 整场/整节重写不合格暂存稿 -> 回填本节独立回执 -> commit-section -> 原子写入正文 -> 下一节`

禁止先写完整篇，再批量伪造逐节计划、复核或映射。

正文放行后必须按 [逐节正文进度硬闸](section-progress-gate.md) 初始化状态。当前节未输出 `section_passed` 时，不得创建下一节标题；不得在一次正文写入中新增两个或以上数字小节。当前节通过前，`正文.md` 中不得出现它；只能在暂存稿中写作。

## 一次成文硬闸

- 写前把全部 E/P 拍聚合成 `1-3` 个真实场面，不得把每拍当成一句任务清单。
- 每个场面先写清 `进场压力 -> 至少三步施压/接招 -> 转折动作 -> 可见后果 -> 余波`，再分配字数。
- 事件不得仅以“发生了什么”的概括句出现。承重事件必须让读者现场经历人物看见什么、想护住什么、怎样接招、在哪个动作上失去位置，以及后果如何停在身体、物件或关系中。
- 落盘前按正式口径计数。暂存稿不在预算内，不得写入正文；必须按场面计划整场或整节重写。
- 禁止把“先写简稿 -> 补对白 -> 补背景 -> 补感受 -> 补够字数”当作逐节写作。这是整稿后扩写的小节缩影，直接判失败。
- 写入正文后，只允许更正错别字、标点、明确的事实连续性错误。凡涉及字数不足、场面不完整、情绪不足、人物没有接招或事件概括化，必须废除暂存稿并整场或整节重写，不得追加补丁。

## 首写约束包

只保留本节会实际遇到的 `5-9` 条正向约束。用人物与场面语言写，不复制失败码、候选词表或回执字段。

优先从以下规则族选取：

- 对白：说清当前对象、压力和接招；允许停顿、答偏、找补，禁止一轮对白完成借口、调度和补偿三项任务。
- 动作：写出执行者、具体对象和可见后果；持物或姿态动作必须有去向、阻力或关系变化。
- 关系：先让读者懂谁偏向谁、谁失去什么，再让职业动作把伤害做实。
- 因果：触发动作先于伤口、破损等状态；人物提问、知情和第三人去向必须有可见来源。
- 人物：按本人的欲望、羞耻、防御和错答方式说话；换一个人仍能原样使用的关键对白不进入首稿。
- 叙述：让动作、物件和话轮承担意义；不用作者总结、抽象认知宣告或解释性比喻替现场盖章。
- 声线：主体原文独占句面与气口；辅助来源只提供情节机制，不提供表达方式。

首写约束必须具体到本节。例如写“丈夫被问钥匙时先抢回钥匙、再改答门锁问题”，不要写“对白要自然”。

## 提交前即时复核

写完暂存稿后、写入正文前，读取本节完整文本，对所有动作、对白和信息转向逐项判断：

1. 动作是否有对象、方向和可见变化。
2. 每句对白由谁说、在回答什么、是否改变对方动作或关系位置。
3. 具体争夺是否写清归属、接收者和现实后果。
4. 伤口、破损、知情、去向和外部压力是否已有触发来源。
5. 核心对白换人后是否仍能原样成立。
6. 是否出现作者代判、主题总结、程序标签或功能句压缩。
7. 删除职业名词后，关系伤害是否仍然成立。
8. 本节领取的 P 拍、E 拍、声线与人物计划是否在真实句子中兑现。
9. 每个承重场面是否同时拥有进场压力、来回接招、转折动作、现实后果和情绪余波，而非只有事件结论。
10. 字数是否已经在预算中，且没有靠相关性低的回忆、职业流程、旁白解释或重复对白填充。

检查必须引用当前小节真实原句。发现错别字或单点事实错误时可定点修正暂存稿。发现场面、共情、接招链、事件表演或字数容量问题时，必须重写对应整场或整节暂存稿，并重新检查全部映射。不得在末尾追加一段填补。

## 边界

- 首写遵守不等于验收通过；只有真实句子存在后才能判断省略、归属、视距、知情和人物互换。
- 本节即时通过不等于全文通过；章尾同构、跨节重复、长窗节奏和全局对白模式仍留到用户授权的写后深审。
- 首稿阶段不运行去 AI 味、滑窗审计、禁词清零或固定密度配平。
- 全文 `bind-draft` 只能在逐节进度闸输出 `final_ready` 后运行；它只汇总最终 SHA 和复核骨架，不能替代已经发生的逐节验收。
