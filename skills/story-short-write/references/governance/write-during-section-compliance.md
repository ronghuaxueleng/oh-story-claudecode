# 逐节随写合规

这份规则把逐节写后检查前移到首写，同时保留对真实句子的即时验收。目标是减少返工，不是让正文背着验收表生成。

## 固定时序

每个数字小节都执行：

`选取本节适用规则 -> 改写成正向约束 -> 连同落笔包首写 -> 检查真实句子 -> 只修本节 -> 回填映射 -> 下一节`

禁止先写完整篇，再批量伪造逐节计划、复核或映射。

## 首写约束包

只保留本节会实际遇到的 `5-9` 条正向约束。用人物与场面语言写，不复制失败码、候选词表或回执字段。

优先从以下规则族选取：

- 对白：说清当前对象、压力和接招；允许停顿、答偏、找补，禁止一轮对白完成借口、调度和补偿三项任务。
- 动作：写出执行者、具体对象和可见后果；持物或姿态动作必须有去向、阻力或关系变化。
- 关系：先让读者懂谁偏向谁、谁失去什么，再让职业动作把伤害做实。
- 因果：触发动作先于伤口、破损等状态；人物提问、知情和第三人去向必须有可见来源。
- 人物：按本人的欲望、羞耻、防御和错答方式说话；换一个人仍能原样使用的关键对白不进入首稿。
- 叙述：让动作、物件和话轮承担意义；不用作者总结、抽象认知宣告或解释性比喻替现场盖章。
- 声线：主体原文独占句面与气口；辅助来源只提供情节机制，不提供表达方式。

首写约束必须具体到本节。例如写“丈夫被问钥匙时先抢回钥匙、再改答门锁问题”，不要写“对白要自然”。

## 写后即时复核

写完本节后读取本节完整正文，对所有动作、对白和信息转向逐项判断：

1. 动作是否有对象、方向和可见变化。
2. 每句对白由谁说、在回答什么、是否改变对方动作或关系位置。
3. 具体争夺是否写清归属、接收者和现实后果。
4. 伤口、破损、知情、去向和外部压力是否已有触发来源。
5. 核心对白换人后是否仍能原样成立。
6. 是否出现作者代判、主题总结、程序标签或功能句压缩。
7. 删除职业名词后，关系伤害是否仍然成立。
8. 本节领取的 P 拍、E 拍、声线与人物计划是否在真实句子中兑现。

检查必须引用当前小节真实原句。发现问题后只修改当前小节，并重新检查受影响的前后话轮、因果链及文字/情绪映射。

## 边界

- 首写遵守不等于验收通过；只有真实句子存在后才能判断省略、归属、视距、知情和人物互换。
- 本节即时通过不等于全文通过；章尾同构、跨节重复、长窗节奏和全局对白模式仍留到用户授权的写后深审。
- 首稿阶段不运行去 AI 味、滑窗审计、禁词清零或固定密度配平。
